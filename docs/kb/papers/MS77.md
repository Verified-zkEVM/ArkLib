# MS77

## At A Glance

`MS77` is MacWilliams–Sloane, *The Theory of Error-Correcting Codes*, North-Holland Mathematical
Library 16 (copyright 1977). The checked artifact is the corrected third printing (1981), ISBN
0-444-85009-0 / 0-444-85010-4.

## What ArkLib Uses From This Paper

Chapter 10, §11, Lemma 7, equation (16), printed page 309: if `0 < δ < 1` and `δn` is an integer,
then the binary binomial shell satisfies

`2^{n·H₂(δ)} / √(8nδ(1−δ)) ≤ C(n,δn)`.

ArkLib uses this estimate to derive the q-ary single-shell bound and then the Hamming-ball bound
behind [ABF26] Corollary 3.8.

`qary_shell_entropy_lower` and `linear_lambda_ge_entropy_volume` in

## Known Divergences From ArkLib

MS77 states a binary **shell** estimate, not the q-ary Hamming-ball formula attributed to it by
ABF26. The in-tree q-ary theorem is nevertheless valid: multiply the binary estimate by
`(q−1)^{δn}`, use
`q^{n·H_q(δ)} = (q−1)^{δn}·2^{n·H₂(δ)}`, and observe that the ball contains that shell. This is a
proved algebraic generalisation, not a verbatim source statement. The checked source assumes only
`0 < δ < 1` plus `δn` integrality; it has no `δ ≤ 1−1/q` condition.

`δ·n` must be an integer, and this is not decoration: at `ρ = 1`, `δ = 1/(2n)` the right-hand side
exceeds `1` while the relative ball collapses to radius `0` and `Λ = 1`.
