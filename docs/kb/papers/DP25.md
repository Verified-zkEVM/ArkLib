# DP25

## At A Glance

`DP25` is the EUROCRYPT 2025 version of Diamond–Posen, *Succinct Arguments over Towers of Binary
Fields*. The same paper is keyed `DP23` for its ePrint preprint (Paper 2023/1784); both entries
exist in `references.bib` and both are in use, so **check which one a docstring means before
following it**. (`DP24` is a *different* Diamond–Posen paper, *Polylogarithmic proofs for
multilinears over binary towers*.)

ArkLib touches this paper from one direction only: it is the reference ABF26 gives for the fact
that an extension code has the same minimum distance as its base code.

## What ArkLib Uses From This Paper

- **Theorem 3.2** — `δmin(C_B) = δmin(C_F)` for the extension code `C_F` of a base code `C_B`.
  ABF26 §2.6 cites this in passing ("see e.g. [DP25, Thm 3.2]") when introducing extension codes.

Nothing else from the paper is used here; the binary-tower commitment scheme, the PLONKish
variant, and the Keccak benchmarks are out of scope for the coding-theory layer.

## Main ArkLib Touchpoints

- [`ArkLib/Data/CodingTheory/ExtensionCodes.lean`](../../../ArkLib/Data/CodingTheory/ExtensionCodes.lean)
  — `minDist_extensionCode_eq_interleaved` is the generic coordinate-isometry bridge and
  `minDist_extensionCode` proves DP25 Theorem 3.2 for a base `B`-linear code. The same module
  also formalizes ABF26 Definition 2.20 at encoder and code-image level.

## Version Notes

Three keys in `references.bib` name Diamond–Posen work, and they are easy to confuse:

| Key | Paper | Venue |
|---|---|---|
| `DP23` | Succinct Arguments over Towers of Binary Fields | ePrint 2023/1784 (preprint) |
| `DP25` | Succinct Arguments over Towers of Binary Fields | EUROCRYPT 2025 (this page) |
| `DP24` | Polylogarithmic proofs for multilinears over binary towers | ePrint / separate paper |

Use `DP25` for the coding-theory result ArkLib cites, matching what `ABF26` and `BCFW25` both
cite. Do not introduce a further spelling: a key with no `references.bib` entry makes
`scripts/kb/extract_lean_citations.py` drop the whole citing file from the citation map.

## Known Divergences From ArkLib

**The formal theorem is slightly more reusable than the cited statement.**
`minDist_extensionCode_eq_interleaved` first proves, for an arbitrary base-code set, that the
presentation-coordinate equivalence is a Hamming isometry from the extension code to the
interleaved base code. `minDist_extensionCode` then combines that bridge with general
interleaving distance preservation to obtain DP25 Theorem 3.2 for a base `B`-submodule. No
systematicity hypothesis is needed. ArkLib also supplies `extensionEncode` and the encoder-level identity
`extensionEncode_comp_algebraMap`, so the encoder-level presentation is expressible as well.

## Open Formalization Gaps

- None for the coding-theory statement ArkLib cites: Theorem 3.2 is proved. The paper's
  binary-tower commitment and proof-system results remain outside this coding-theory PR's scope.
