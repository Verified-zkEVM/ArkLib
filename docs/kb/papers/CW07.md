# CW07

## At A Glance

`CW07` is Cheng–Wan, *On the list and bounded distance decodability of Reed-Solomon codes*, SIAM J.
Comput. 37(1) (2007) — a reduction from the discrete-logarithm problem to *algorithmic* list decoding
of Reed-Solomon codes beyond the Johnson bound.

## What ArkLib Uses From This Paper

Nothing. It is [ABF26] Theorem 3.16 (Theorem 3.15 in the cached PDF build), the only §3 statement
absent **by decision**.

## Open Formalization Gaps

The statement is a reduction, so it needs a computational-hardness framework — an
adversary/advantage/running-time layer over the code — that ArkLib does not have. Written without one it
would be either vacuous or a claim about something other than hardness. [ABF26] itself notes that modern
SNARK constructions do not require efficient list decoding, so this is not an obstruction in context.
